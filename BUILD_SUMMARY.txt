🎯 CLI COMMANDS AVAILABLE
================================================================================

1. metrics get <metric_id>
   → Get metric data from Snowflake
   Options: --product, --format, --output, --filter

2. metrics search <keyword>
   → Search for metrics
   Options: --product, --category

3. metrics list <product>
   → List all metrics in product
   Options: --category

4. metrics describe <metric_id>
   → Show metric details
   Options: --product

5. metrics products
   → List all products and metric counts

6. metrics validate
   → Validate metric definitions
   Options: --product

7. metrics audit
   → View audit logs
   Options: --user, --action, --limit

8. metrics auth
   → Manage Snowflake authentication
   Options: --relogin

9. metrics --help
   → Show all available commands

🐍 PYTHON LIBRARY API

from engine.metric_engine import MetricsEngine

engine = MetricsEngine()

# Get metric data
result = engine.get_metric(
    metric_id='trial_signups_total',
    product='trial',
    filters={'start_date': '2026-01-01'},
    user_id='user@example.com'
)

# Search metrics
results = engine.search_metrics(
    keyword='adoption',
    product='designer'
)

# List metrics in product
metrics = engine.list_metrics(product='plans')

# Get metric information
info = engine.get_metric_info(
    metric_id='designer_2025_adoption_rate',
    product='designer'
)

# View products
products = engine.get_products()

# Audit logs
logs = engine.audit_logger.get_logs(
    filters={'user_id': 'user@example.com'}
)

# Clean up
engine.close()
