🚀 Generate Your Own Metrics from Snowflake!

5 Easy Steps:

1️⃣ Run in Snowflake:
DESC DISCOVERY_PRODUCT_MANAGEMENT.METRIC_STORE.<YOUR_VIEW_NAME>

2️⃣ Copy columns output

3️⃣ Fill this template:
   PRODUCT: [Ask Alteryx / Trial / Plans / Version Adoption / Live Query]
   VIEW: [Your view name from step 1]
   COLUMNS: [Paste DESC output]

4️⃣ Go to: https://claude.ai
   Paste this prompt:
   
   "Generate a metrics markdown file.
   PRODUCT: [YOUR_PRODUCT]
   VIEW NAME: DISCOVERY_PRODUCT_MANAGEMENT.METRIC_STORE.[YOUR_VIEW]
   VIEW SCHEMA: [PASTE COLUMNS]
   
   Create markdown with:
   | Product | Metric Name | Description | SQL Query | Tags |
   Include 15+ metrics from the view with complete SQL queries."

5️⃣ Save Claude's output as: {product_name}.metrics.md

Done! You now have a metrics file ready to use. 🎉
